# Fonts for Neuron Space

The page wears kevinferron.com's look, and its two fonts are served from this
origin, `public/fonts/`, by Vite — the page fetches no font from anywhere else.

| File | Family | Licence |
|---|---|---|
| `JosefinSans-wght.ttf` | Josefin Sans (variable, weight 100 to 700) | SIL OFL 1.1, **Reserved Font Name "Josefin Sans"** (`OFL-JosefinSans.txt`) |
| `PixelifySans-wght.ttf` | Pixelify Sans (variable, weight 400 to 700) | SIL OFL 1.1, no Reserved Font Name (`OFL-PixelifySans.txt`) |

Both are unmodified copies of the upstream bytes from github.com/google/fonts
(`ofl/josefinsans/JosefinSans[wght].ttf`, `ofl/pixelifysans/PixelifySans[wght].ttf`),
the same files `agent-neuron` keeps in `assets/fonts/` for its people page. Josefin
Sans carries a Reserved Font Name, so it must not be subset, converted or edited
here. The fonts are under the OFL, not the repo's MIT licence.
